LOOPS · INT

Tính tổng từ 1 đến n

Viết hàm nhận số nguyên n và trả về tổng 1 + 2 + … + n. Với n = 5, kết quả cần là 15.

VÍ DỤsumTo(5) → 15
Tạo biến sum bắt đầu từ 0. Dùng vòng lặp for từ 1 đến n, mỗi lượt cộng i vào sum.
SumCalculator.java
public class SumCalculator {
    public static int sumTo(int n) {
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        return sum;
    }
}

Mỗi vòng lặp cộng thêm i vào sum. Khi i vượt quá n, hàm trả lại tổng đã tích lũy.

02CƠ BẢN
◇
OOP · CLASS

Mô hình hóa một cuốn sách

Tạo class Book có title và price. Dùng constructor để khởi tạo hai thuộc tính và viết getter để đọc dữ liệu.

VÍ DỤnew Book("Clean Code", 12.5)
Đặt thuộc tính là private. Constructor có cùng tên với class và không có kiểu trả về.
Book.java
public class Book {
    private String title;
    private double price;

    public Book(String title, double price) {
        this.title = title;
        this.price = price;
    }

    public String getTitle() { return title; }
    public double getPrice() { return price; }
}

Đóng gói dữ liệu trong class giúp giới hạn việc sửa trực tiếp thuộc tính và tạo một giao diện sử dụng rõ ràng.

ARRAYS · LOOP

Tìm giá trị lớn nhất

Cho một mảng số nguyên không rỗng. Duyệt mảng và tìm phần tử lớn nhất mà không dùng thư viện ngoài.

VÍ DỤ[4, 9, 2, 7] → 9
Cho max bằng phần tử đầu tiên, sau đó so sánh từng phần tử còn lại với max.
ArrayMaximum.java
public class ArrayMaximum {
    public static int maxOf(int[] numbers) {
        int max = numbers[0];
        for (int number : numbers) {
            if (number > max) {
                max = number;
            }
        }
        return max;
    }
}

Bắt đầu từ numbers[0] để lời giải vẫn đúng khi mọi phần tử đều âm.
