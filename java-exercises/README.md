# Java Practice Lab — source exercises

Standalone Java examples paired with the interactive [Java Practice Lab](../java-practice.html).

## Requirements

- Java Development Kit (JDK) with `javac` and `java` available in the terminal.

## Compile and run

From this folder, compile the three examples:

```sh
javac SumCalculator.java Book.java ArrayMaximum.java
```

Run any example:

```sh
java SumCalculator
java Book
java ArrayMaximum
```

Each class includes a small `main` method so it can be tried independently. The methods are also designed to be reused from other Java programs.
